# Escucha & Relaciona — Entrega 2

Juego web donde el **sonido es la interfaz**: escuchas un sonido cotidiano y eliges la imagen que le corresponde.

**Taller de Interfaces · UAI 2026 · Prof. Jorge Forero**

## Concepto pedagógico
Entrena la **percepción auditiva** y la asociación sonido–objeto. El usuario no puede avanzar sin escuchar: el audio es la pista principal, no un acompañamiento. A lo largo de 8 rondas con puntaje, se ejercita reconocer e identificar sonidos del entorno.

## Cómo jugar
1. Pulsa **Comenzar**.
2. En cada ronda, presiona **Escuchar sonido** y elige la fotografía correcta.
3. Suma puntos y revisa tu resultado final; puedes **volver a jugar**.

## Estructura
- `index.html` — juego (HTML / CSS / JS).
- `audio/` — sonidos procesados en formato web (MP3/OGG).
- `img/` — imágenes de las opciones.

## Tecnología
HTML, CSS y JavaScript. El audio se editó en una DAW (recorte) y se exportó optimizado para web.

## Créditos
Sonidos e imágenes: pixbay, audacity 4, max 9, magnific.
